# ASTRA-66 — Visual index

Every image here is **generated by the project's own pipeline** from the CAD model, the analysis or the simulation.
Nothing is a photograph, a rendering made by hand, or a measurement: no hardware exists and nothing has flown.
Trajectory plots use the **placeholder** motor data, so they show software behaviour and sensitivities, not
predictions. ASTRA-66 is NOT FLIGHT CERTIFIED.

Files are referenced where the pipeline writes them, so nothing is duplicated in the repository.
