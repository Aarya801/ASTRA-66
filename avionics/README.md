# avionics/

The electronics handle sensing, logging and telemetry only. **No channel can drive an igniter, charge or any energetic device.**
Recovery uses the certified motor's own ejection, prepared by a mentor.

> **Phase 4 status: software architecture and simulation only. The avionics are NOT flight certified.** No avionics
> component has been selected, built or tested; every sensor is **COMPONENT TO BE SELECTED**. All data in this folder
> are **SIMULATED** and labelled as such. Real-time and flight capability have not been demonstrated.

## Quick start (no hardware needed)

```bash
python -m avionics.firmware.simulate_flight
python avionics/analysis/flight_data_analysis.py avionics/data/example/example_flight_simulated.csv
python avionics/ground_station/server.py --simulate --speed 2
python -m unittest discover -s avionics/tests -t .
```

The third command serves the dashboard at http://127.0.0.1:8766/ (localhost only). `python run_validation.py` runs the
avionics tests together with the rest of the project.

## Mechanical provisions (CAD rev B)
- **Sled** (`cad/parts/AV-306_electronics_sled.scad`):
  - 10 M2.5 insert bosses on a 25 mm pitch;
  - switch tower with an M2.5 insert (height `SW_TOWER_H`, USER);
  - 2 M3 inserts for the battery cage;
  - zip-tie slots.
- **Battery cage** `AV-308`: open bottom, strap-retained. The cell must be no wider than 28.8 mm to clear the rod sleeves.
- **GPS / sensor tray** `PL-202`: in the payload bay under the service hatch; 6 M2.5 bosses.
- **Camera cradle** `PL-203`, with the lens cowl `PL-204` at 270°, tilted 15° aft.
- **Placeholder envelopes:** module, battery, GPS, camera and switch envelopes are in `cad/parts/COTS_envelopes.scad`. Replace them with your measured parts and re-run the CAD pipeline. Interference and clearance are re-checked automatically.

Phase 4 did not change any CAD file. How the avionics must fit these provisions is set out in
`architecture/interface_spec.md` §3.
