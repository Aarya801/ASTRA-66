# avionics/

The electronics handle sensing, logging and telemetry only. **No channel can drive an igniter, charge or any energetic device.**
Recovery uses the certified motor's own ejection, prepared by a mentor.

| File | Kind | Content |
|---|---|---|
| `electronics.csv` | generated by `build.py` | Module list: function, example class (verify datasheets), bus, location, cost, build level |
| `diagrams/arch.svg` | generated | System architecture: modules, interfaces I-00…I-08, load paths |
| `diagrams/elec.svg` | generated | Avionics block diagram (power, I²C, SPI, UART, GPIO) |
| `diagrams/fsm.svg` | generated | Flight-phase detection state machine (logging only) |

## Mechanical provisions (CAD rev B)
- **Sled** (`cad/parts/AV-306_electronics_sled.scad`):
  - 10 M2.5 insert bosses on a 25 mm pitch;
  - switch tower with an M2.5 insert (height `SW_TOWER_H`, USER);
  - 2 M3 inserts for the battery cage;
  - zip-tie slots.
- **Battery cage** `AV-308`: open bottom, strap-retained. The cell must be no wider than 28.8 mm to clear the rod sleeves.
- **GPS / sensor tray** `PL-202`: in the payload bay under the service hatch; 6 M2.5 bosses.
- **Camera cradle** `PL-203`, with the lens cowl `PL-204` at 270°, tilted 15° aft.
- **Placeholder envelopes:** module, battery, GPS, camera and switch envelopes are in `cad/parts/COTS_envelopes.scad`. Replace them with your measured parts and re-run the CAD pipeline. Interference and clearance are re-checked automatically.

Firmware is not part of this repository yet (see §19 of the engineering package for planned work).
