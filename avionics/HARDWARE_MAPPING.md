# ASTRA-66 avionics — hardware-agnostic interface map

> **No avionics hardware has been selected, bought, bench-tested or flown. The avionics are NOT flight certified.** This
> map links each logical software component to a generic class of commercially available, student-accessible hardware.
> Where the project already names a candidate class (`avionics/electronics.csv`, generated by `build.py`), it is kept
> as is; its datasheet values have **not** been checked. Nothing here is a validated part. Every item is
> **COMPONENT TO BE SELECTED** until a mentor-reviewed selection is recorded with datasheet references.

## 1. Map

Legend: **Required** / **Optional** follows the existing `build` column of `avionics/electronics.csv` ("both" =
required in both builds, "rec" = recommended build only). ✔ = applies.

| Logical component (software) | Generic hardware class | Existing candidate class (kept, datasheet not verified) | Interface | Required / Optional | Prototype assumption | Needs bench validation | Needs flight/range approval |
|---|---|---|---|---|---|---|---|
| Flight computer (`flight_computer.py`) | Low-power microcontroller board | RP2040 or ESP32-S3 dev board | — | **Required** | ✔ loop timing, memory and µs timer assumed adequate | ✔ loop rate, SD latency, power draw | ✔ as part of the flight-readiness review |
| IMU (`sensor_interfaces`, `imu`) | 6-axis (or 9-axis) digital IMU breakout | 6-axis ±32 g class breakout | I²C or SPI | **Required** | ✔ ≥ ±16 g, ≥ ±1000 deg/s, 100 Hz; axis mapping | ✔ bias, noise, saturation, mounting | ✔ via flight-readiness review |
| Barometer (`baro`) | Digital pressure sensor breakout | BMP390 or MS5611 class breakout | I²C or SPI | **Required** | ✔ 30–110 kPa, 50 Hz | ✔ noise, static-port lag, bay leak | ✔ via flight-readiness review |
| GNSS (`gnss`) | UART GNSS module + antenna | u-blox M8/M9/M10 class + patch antenna | UART | Optional | ✔ ≥ 1 Hz, fix after boost | ✔ time to fix, lock under the tube, interference from the radio | — |
| Temperature (`temperature`) | Digital temperature sensor, or the barometer's internal channel | TMP117 class breakout or barometer internal sensor | I²C | Optional | ✔ −20…+60 °C | ✔ self-heating | — |
| Battery monitor (`battery`) | ADC input + resistor voltage divider | none listed: added in Phase 4 (MCU ADC, divider values not chosen) | ADC | **Required** (Phase 4 requirement) | ✔ 0–5 V input range | ✔ divider calibration, sag under load | — |
| Battery | 1S LiPo with protection circuit | 1S LiPo, JST-PH, in AV-308 cage | power | **Required** | ✔ ≤ 28.8 mm wide; capacity for the pad hold | ✔ endurance on the pad (test T-10), retention | ✔ range rules on LiPo handling and charging |
| Power regulation | 3.3 V LDO or buck regulator | 3.3 V LDO or buck (≥ 500 mA) | power | **Required** | ✔ current budget | ✔ brown-out margin | — |
| Power switch AV-307 | Latching switch, externally accessible | COTS latching switch, screw or key type (BOM part AV-307, listed there as "arming switch"; it only switches power to the electronics) | power | **Required** (BOM) | ✔ fits the switch-band hole | ✔ cannot switch off under vibration | ✔ range procedures for switching electronics on at the pad |
| Storage (`logging`, `CsvLogSink`) | microSD card + SPI socket, or equivalent flash | microSD SPI breakout + high-endurance card | SPI | **Required** | ✔ sustained write ≥ log rate × ~110 B/row | ✔ write latency, power-loss behaviour, retention in vibration | — |
| Telemetry radio (`telemetry`, `HardwareTelemetryLink`) | Legal low-power telemetry radio module (pair) | Semtech SX127x LoRa module pair, **only on a band and power legal where used** | SPI | Optional | ✔ 41-byte packets at 5 Hz | ✔ link range and loss (test T-14), antenna placement | ✔ **frequency / power legality and range frequency coordination** |
| Separation sense | Breakwire loop + digital input | Thin enamel wire + 2-pin connector across I-03 | GPIO **input** only | **Required** | ✔ continuity logic | ✔ continuity and bounce (test T-15) | — |
| Buzzer + LED | Active piezo buzzer, status LED | Active piezo buzzer, status LED | GPIO (annunciation only) | **Required** | ✔ | ✔ audible on the pad / after landing | — |
| Camera | Self-contained action / FPV recorder | Mini recorder with its own battery (USER choice) | none (standalone) | Optional | ✔ mass 35 g placeholder | ✔ field of view through the ⌀14 mm hole | ✔ via flight-readiness review (mass, retention) |
| Ground station (`ground_station`) | Second radio module + MCU + USB to a laptop | 2nd LoRa module + MCU + USB (Python logger) | USB serial | Optional | ✔ | ✔ real-time display with real packets | ✔ same radio legality as above |

There is **no** actuator, igniter, pyrotechnic, energetic-device or deployment output in this map, and none may be
added: the flight computer only reads sensors and writes data. Recovery uses the certified motor's own ejection,
prepared by a mentor. Propulsion is an external, commercially certified component and is not part of the avionics.

## 2. Interface-requirement shortlist (what a candidate must satisfy)

These are **requirements for selection**, not specifications of any part. Ranges derived from the simulation use the
PLACEHOLDER propulsion input and must be re-derived with the certified motor's published data.

| Component | Must have | Should have | Check on the bench |
|---|---|---|---|
| Microcontroller | I²C + SPI + UART + ADC; free-running µs timer; enough RAM for SD buffering | open, maintained drivers for the chosen sensors; USB for configuration | 100 Hz loop with margin while logging and transmitting |
| IMU | accelerometer full scale ≥ ±16 g; gyro ≥ ±1000 deg/s; ≥ 100 Hz output; documented axis orientation | selectable anti-alias filter; FIFO | bias and noise at rest; axis mapping to +z nose |
| Barometer | 30–110 kPa range; ≥ 20 Hz (50 Hz preferred) | oversampling / IIR filter settings; temperature output | noise at rest; response through the 4 × ⌀2 mm static ports |
| GNSS | UART output of position, fix type and satellites at ≥ 1 Hz | ≥ 5 Hz; high-dynamics / airborne mode; external or patch antenna | cold / warm time to fix inside the airframe |
| Temperature | −20…+60 °C | 0.5 °C accuracy or better | offset against a reference; self-heating |
| Battery monitor | divider keeping the ADC input in range at 4.2 V | high-value divider (low drain) with calibration | reading vs a multimeter across 3.3–4.2 V |
| Storage | sustained writes above the log data rate; FAT-compatible | industrial / high-endurance card | 1 h continuous log; pull-power test (CRC-16 rows show the damage) |
| Radio | legal band and power where operated; SPI | configurable data rate; CRC in the modem | range walk test at ≥ 2× the expected distance (T-14) |
| Mechanical fit (all boards) | within the CAD envelopes and existing M2.5 bosses (`documentation/CAD_AVIONICS_INTEGRATION.md`) | IMU near the roll axis | measure each board with headers and connectors; weigh everything |
