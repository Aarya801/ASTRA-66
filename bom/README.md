# bom/

Generated by `python build.py` from `documentation/generator/data_tables.py`. Do not edit the CSVs by hand.

| File | Content |
|---|---|
| `bom.csv` | Every part: part no., qty, material, method, dimensions, tolerance, interface, assembly, make/buy, cost range, build level |
| `fasteners.csv` | Metric fasteners and heat-set inserts with standard and location |
| `materials.csv` | Stock materials, quantities and cost ranges |

Costs are USD planning ranges (ASSUMPTION). Motors, tools and shipping are excluded.
Parts marked EXTERNAL (motor, igniter) are never fabricated.
