Important limitations

What is ASTRA-66?

ASTRA-66 is a first-year student aerospace engineering project: a modular 66 mm-class, 1144 mm model rocket airframe designed as a complete, reproducible engineering package rather than as a build. It combines:

  • Parametric CAD — 25 parts and a master assembly generated from one parameter file, validated by measuring the rendered mesh.
  • Engineering analysis — mass budget, centre of gravity, Barrowman centre of pressure, static margin, structural load cases and recovery sizing, each value carrying a provenance tag.
  • Flight simulation — a 1-DOF vertical model with an ISA atmosphere and a component drag build-up, checked against independent references.
  • Avionics software — hardware-independent sensor interfaces, state estimation, flight-state classification, schema-validated logging and a CRC-checked telemetry packet. No actuation of any kind.
  • Telemetry and data handling — a ground-station receiver and dashboard, post-flight analysis and a synthetic sensor replay that runs through the real flight-computer code.
  • Automated validation — one command regenerates and re-checks the whole chain in continuous integration on two Python versions.
  • Documentation — 20 engineering documents including a full limitations register.
  • 3D visualization — this site.

The adapter reads 17 repository files and records a SHA-256 of each one; the list is in the DATA PROVENANCE panel of the simulator. If a value is not in the repository, the interface shows NOT AVAILABLE rather than inventing one.

Safety boundary

ASTRA-66 covers airframe structure, aerodynamics, recovery sizing, simulation and flight-data software only. It contains no propulsion, propellant, igniter or pyrotechnic design; propulsion appears only as an external, commercially certified component envelope. Any physical activity would require a qualified mentor, a recognised rocketry organisation and compliance with local law.
